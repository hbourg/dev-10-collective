### Definitions
- User: A person without an account and is not verified to be associated with Dev10
- Member: A verified Dev10 associate or alumni with an active account
- Alumni: A person with previous history to Dev10 without an active account
- Admin: A verified Dev10 personnel with high level permissions to member accounts


### User
- I cannot view the map of where other members are located

### Member
- I want to add my location to the map so other people can see where I am located
- I want to be able to view the map and see where other members are located
- If I move locations, I can update my old location to my new location

### Discord User
- I want to enter a command to add my city, state
- I want to enter a command to privately view the directory map in external browser

### Admin
- Send invites via email to an alumni
- Create accounts for Dev10 alumni
- Remove members
- Edit member details
- Edit member roles
